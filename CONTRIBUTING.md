# Contributing

1. Keep examples placeholder-only and machine-independent.
2. Run `bash -n` on every changed shell script.
3. Run `tests/shell-test.sh` before opening a pull request.
4. Add a regression check for changed proxy, cleanup, or configuration behavior.
5. Never commit `.env`, live MCP configuration, tokens, logs, or generated clean homes.
